I just launched my first open-source project: a CLI tool that cleans up messy CSV files.

If you've ever lost an afternoon to inconsistent headers, stray whitespace, duplicate rows or broken encodings before you could even start on the data, this one's for you. It fixes all of that from the command line, so you get to the real work sooner.

It's free, and I'd really like feedback. Issues and pull requests are welcome if something's missing.
