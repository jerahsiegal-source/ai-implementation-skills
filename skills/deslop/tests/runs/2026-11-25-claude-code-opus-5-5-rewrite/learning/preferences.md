# deslop preferences

Learned from your own edits by `/deslop learn`. Private: this file never goes in a repo.
These are cleanup rules: what to cut, titles, layout, sentence shape, markers.
Voice and word choice belong to your voice skill (my-voice), not here.
A rule applies once it is `confirmed` or seen 2+ times. Edit or delete any line.

## Rules
- [all] [seen 2] No title line on short pieces (a few paragraphs): start with the first sentence.

## Candidates (seen once)
- [all] [seen 1] No section headings in short pieces; let paragraphs carry the structure.
- [all] [seen 1] Cut follow-up and reassurance closers ("we'll come back to you if...", "we'll keep you posted").
- [all] [seen 1] Write short lists (about 3 items) as plain sentences in one paragraph, not a numbered or bulleted list.
