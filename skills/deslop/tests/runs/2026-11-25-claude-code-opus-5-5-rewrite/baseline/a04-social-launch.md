I put my first open-source project out today. It's a small command-line tool for cleaning up messy CSV files.

I made it because I kept losing afternoons fixing CSVs before I could even start on the analysis: headers that don't match, extra whitespace, duplicate rows, broken encodings. Now one command takes care of that and I can get on with the work I actually meant to do.

It's free and open source. If you try it, let me know what breaks or what's missing. Issues and pull requests are welcome.
