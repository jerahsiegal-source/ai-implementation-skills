# Hearth & Crumb

## Baked by family, since 2012

We opened Hearth & Crumb in 2012 with one oven, a borrowed mixer and a lot of early mornings. Portland has kept us going ever since.

## What we make

Bread comes first. Every loaf starts the day before as a slow-rising dough, so the flavor has time to develop. We also make croissants, scones, seasonal pies, and cookies that sell out before noon.

We use real butter, fruit that's in season, and local flour when we can get it. No shortcuts. If we wouldn't serve it at our own table, we don't make it.
