I just launched my first open-source project, a CLI tool that cleans up messy CSV files.

If you've ever lost an afternoon fixing inconsistent headers, stray whitespace, duplicate rows or broken encodings before you could even look at the data, this is for you. It handles those chores from the command line so you get to the actual analysis sooner.

It's free and open source, and I'd love feedback. Issues and pull requests are welcome if something's missing.
