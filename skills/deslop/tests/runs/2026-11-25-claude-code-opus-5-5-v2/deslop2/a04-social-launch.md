I just launched my first open-source project: a CLI tool for cleaning up messy CSV files.

If you've ever spent an afternoon fixing inconsistent headers, stray whitespace, duplicate rows, or broken encodings before you could even start analyzing data, this is for you. The tool handles those chores from the command line so you can get to the real work faster.

It's free and open source, and I'd love your feedback. If something's missing, open an issue or send a pull request.
