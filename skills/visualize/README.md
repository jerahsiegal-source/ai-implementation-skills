# Visualize

Turns a big answer into one interactive page: the verdict up top, what needs you, and every detail one click away with its source.

Type `/visualize` (Claude Code) or `$visualize` (Codex):

```
/visualize where this project stands
/visualize the research you just did
/visualize how these services connect
```

## Building blocks

| Block | Best for |
|---|---|
| Health Brief | A short status update on one project |
| Pulse Board | Many workstreams at once |
| Insight Tabs | Research findings, each claim beside its proof |
| Margin Notes | A recommendation or comparison with sources in the margin |
| Mission Map | Systems, complex workflows and dependencies |
| Decision Desk | Decisions you need to make, with a recommendation |

Big projects get a combined page: one header, then the blocks you need as tabs. When nothing fits, Visualize makes a new block in the same look.

Open any file in [blocks/](blocks/) in a browser to try them. The bar at the top switches blocks and looks (Studio, Paper, Night).

Needs only the shared [design kit](../design-kit). Install with the repo's install script.
