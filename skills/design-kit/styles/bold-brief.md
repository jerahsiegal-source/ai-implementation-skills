# Bold Brief
Status: candidate
Feel: editorial, confident, decisive
Best for: executive summaries, decision memos, one-page briefs, progress for a boss
Not for: dense data tables, long technical docs

## Tokens
light: bg #FFFFFF, surface #F4F4F1, ink #111315, muted #555B60, line #DADBD6, accent #1543D6, ok #1C7C47, warn #9A6400, bad #C42B2B, highlight #FFD23F
dark: bg #101214, surface #1A1D20, ink #F2F3F1, muted #A3A9AD, line #30353A, accent #7D9BFF, ok #5FCB8C, warn #F0C04E, bad #F07A7A, highlight #E8BD2A
type: display Archivo 800, body Source Sans 3 400/600, numbers Archivo 700
shape: radius 0 to 4px, strong rules, no shadows
density: balanced

## Moves
- Huge headline that states the verdict, not a topic.
- One giant number block (for example 72% done) beside the headline.
- A full-width highlight band for "Your call" decisions, with dark text on the yellow.
